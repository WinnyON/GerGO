Communication:
    - Using TCP, with unique encoding for the requests:
        0. EXIT
        1. CREATE_DB
        2. DROP_DB
        3. CREATE_TABLE
        4. DROP_TABLE
        5. GET_DB_DETAILS - get a list about the databases and the tables in the system
        6. GET_TABLE_DETAILS
        7. ADD_COLUMN - adds a column to a specified table
        8. ADD_FOREIGN_KEY - adds a foreign key
        9. GET_TABLES - tablenames
        10. GET_FOREIGN_KEYS
        11. INSERT
        12. DELETE
        13. CREATE_INDEX
        14. GET_ALLROWS
